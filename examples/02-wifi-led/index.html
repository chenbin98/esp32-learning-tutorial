沿用案例 01 的 D2 / GPIO2 和 LED 接线。ESP32 开机后默认熄灭，接入路由器，运行一个 HTTP 服务。浏览器打开它的 IP 地址，点击“点亮”或“熄灭”即可控制。

1. 填写 2.4 GHz Wi-Fi

首次配置时，在编辑器里把 examples/02-wifi-led/wifi_config.example.py 复制到 config/，重命名为 wifi_config.py。已有配置则直接编辑，避免覆盖。

WIFI_SSID = "你的2.4GHz网络名称"
WIFI_PASSWORD = "你的Wi-Fi密码"

文件保留普通 Python 字符串赋值。若密码中含引号或反斜杠，按 Python 字符串语法转义。真实密码留在本地配置中，不写进教程。

电脑与 ESP32 可以使用不同频段

本次 ESP32 仅能使用 2.4 GHz。电脑可继续连接同一路由器的 5 GHz 网络，只要路由器允许设备互通。网络名带“5G”不等于扫描证明；实际以开发板能看到的网络为准。

可选：用开发板扫描附近网络
python -m mpremote connect /dev/cu.usbserial-0001 exec "import network; w=network.WLAN(network.WLAN.IF_STA); w.active(True); print([(x[0], x[2], x[3]) for x in w.scan()])"

输出为网络名、信道和信号强度。这个命令会中断当前程序，之后需重新部署或重启。

3. 用浏览器控制

  1. 电脑或手机连接到允许与 ESP32 互通的局域网。
  2. 在浏览器地址栏输入串口打印的 http://设备IP/。
  3. 点击“点亮”，确认网页状态变化，并观察真实 LED。
  4. 点击“熄灭”，重复检查；刷新页面应显示当前 GPIO 状态。

这个入门页面没有自动轮询：另一台设备改变状态后，刷新才会同步显示。设备重启后默认熄灭，IP 由 DHCP 分配，可能改变。

此案例面向可信局域网，没有登录验证或 HTTPS；局域网中能访问它的设备都可以控制 LED。不要将 80 端口直接映射到互联网。

请求怎样变成电平

请求作用
GET /读取 GPIO2 电平，生成带状态文字的 HTML。
POST /onGPIO2 写 1，再返回 303 跳转到首页。
POST /offGPIO2 写 0，再返回 303 跳转到首页。
GET /api/state返回 JSON，如 {"on":true}，供测试或其他客户端读取。

connect_wifi() 负责联网，最长等待约 30 秒；main() 在 80 端口接受连接；handle() 读取请求并控制引脚；respond() 写入 HTTP 响应头和 UTF-8 页面。POST 后跳转首页，刷新时就不会重复提交上一次开关动作。

程序每次处理一个客户端，请求读取超时为 3 秒，请求头最多约 2 KB。它适合学习和少量局域网控制；如果 Wi-Fi 长时间断开，重连超时会结束程序，需要检查网络并重启。

"""ESP32 D2 / GPIO2 web LED control."""
import network
import socket
import time
from machine import Pin
from wifi_config import WIFI_SSID, WIFI_PASSWORD

led = Pin(2, Pin.OUT, value=0)
PAGE = '''<!doctype html><html lang="zh-CN"><meta charset="utf-8">
<meta name="viewport" content="width=device-width,initial-scale=1">
<title>ESP32 LED</title><style>
body{font-family:system-ui;background:#edf2f7;display:grid;place-items:center;min-height:90vh;color:#182b44}
main{background:white;padding:36px;border-radius:24px;text-align:center;width:min(78vw,360px)}
button{font-size:20px;padding:16px 28px;margin:8px;border:0;border-radius:12px;background:#1769e0;color:white;cursor:pointer}
.lamp{width:64px;height:64px;border-radius:50%%;background:%s;margin:24px auto}
p{color:#52647c}</style><main><h1>ESP32 LED</h1><p>D2 · GPIO2</p>
<div class="lamp"></div><h2>当前状态：%s</h2>
<form method="post" action="/on" style="display:inline"><button>点亮</button></form>
<form method="post" action="/off" style="display:inline"><button style="background:#49576a">熄灭</button></form>
<p>连接同一局域网即可控制</p></main></html>'''


def connect_wifi():
    if not WIFI_SSID:
        raise ValueError('Fill in wifi_config.py first')
    wlan = network.WLAN(network.WLAN.IF_STA)
    wlan.active(True)
    wlan.config(reconnects=-1)
    if not wlan.isconnected():
        print('Connecting to Wi-Fi...')
        wlan.connect(WIFI_SSID, WIFI_PASSWORD)
    start = time.ticks_ms()
    while not wlan.isconnected():
        if time.ticks_diff(time.ticks_ms(), start) > 30000:
            status = wlan.status()
            wlan.disconnect()
            raise RuntimeError('Wi-Fi timeout; check 2.4 GHz SSID/password. Status: %s' % status)
        time.sleep_ms(200)
    print('Open in browser: http://%s/' % wlan.ifconfig()[0])
    return wlan


def respond(client, status, body='', content_type='text/html; charset=utf-8', extra=''):
    body = body.encode('utf-8')
    header = ('HTTP/1.1 %s\r\nContent-Type: %s\r\nContent-Length: %d\r\n'
              'Connection: close\r\nCache-Control: no-store\r\n%s\r\n'
              % (status, content_type, len(body), extra))
    client.write(header.encode('utf-8'))
    client.write(body)


def handle(client):
    client.settimeout(3)
    request = b''
    while b'\r\n\r\n' not in request:
        chunk = client.recv(256)
        if not chunk:
            return
        request += chunk
        if len(request) > 2048:
            respond(client, '431 Request Header Fields Too Large')
            return
    parts = request.split(b'\r\n', 1)[0].split()
    if len(parts) != 3:
        respond(client, '400 Bad Request')
        return
    method, path, _ = parts
    if method == b'POST' and path in (b'/on', b'/off'):
        led.value(1 if path == b'/on' else 0)
        respond(client, '303 See Other', extra='Location: /\r\n')
    elif method == b'GET' and path == b'/':
        on = bool(led.value())
        respond(client, '200 OK', PAGE % ('#ffcb45' if on else '#c9d2de', '点亮' if on else '熄灭'))
    elif method == b'GET' and path == b'/api/state':
        respond(client, '200 OK', '{"on":%s}' % ('true' if led.value() else 'false'), 'application/json')
    else:
        respond(client, '404 Not Found', 'Not found')


def main():
    wlan = connect_wifi()
    server = socket.socket()
    server.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
    server.bind(('0.0.0.0', 80))
    server.listen(2)
    server.settimeout(1)
    try:
        while True:
            if not wlan.isconnected():
                connect_wifi()
            try:
                client, _ = server.accept()
            except OSError:
                continue
            try:
                handle(client)
            except OSError as error:
                print('Client error:', error)
            finally:
                client.close()
    finally:
        server.close()
        led.value(0)


if __name__ == '__main__':
    main()

问题先检查什么
Wi-Fi timeoutSSID / 密码是否正确、网络是否为 2.4 GHz、信号与路由器是否正常；修正后重启。
有 IP，但网页打不开地址使用 http://；电脑能否访问同一局域网、是否处于访客网络或 AP 隔离；检查 VPN / 代理对局域网的影响。
