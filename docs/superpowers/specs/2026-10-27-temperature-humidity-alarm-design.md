# 实战项目 01：温湿度报警系统设计

日期：2026-10-27。用户确认采用独立 `projects/` 栏目，并确认 LED 高电平接法。

## 目标

在现有案例教程之外新增“实战项目”栏目。第一个项目组合 DHT11 温湿度网页监测与 LED 阈值报警：温度严格大于 25°C 且相对湿度严格大于 60% RH 时点亮报警灯；任一条件不满足时熄灭。

## 硬件

- ESP32-D0WD-V3；本机 D2 按 GPIO2 使用，D23 按 GPIO23 使用。
- DHT11 沿用案例 04：VCC 接 3V3（具体模块电压规格按其资料确认）、GND 共地、SIG 接 D2 / GPIO2。
- LED 接法：D23 / GPIO23 → 限流电阻 → LED 正极，LED 负极 → GND；高电平点亮。教程使用 330 Ω 作为复现参考值。

## 设备程序

- 复用案例 04 的 Wi-Fi 配置、DHT11 读取、HTTP 页面和 `/api/readings` JSON 模式。
- 新增 `ALARM_LED_PIN = 23`、高电平有效配置和阈值常量 `TEMP_THRESHOLD_C = 25`、`HUMIDITY_THRESHOLD_RH = 60`。
- 每次成功采样后仅当 `temperature > 25 and humidity > 60` 时点亮 LED；否则熄灭。传感器采样间隔仍为 2500 ms，浏览器每秒刷新缓存值。
- 启动时 GPIO23 设为输出低电平，首次有效采样前 LED 保持熄灭。采样失败时保留上一次有效 LED 状态，网页在报警灯状态旁明确标注传感器错误/数据陈旧，串口输出错误；不把无效读数当成正常环境值。
- 网页显示当前温湿度、报警阈值、报警灯状态和传感器状态。Wi-Fi 中断时页面请求失败提示沿用现有做法。
