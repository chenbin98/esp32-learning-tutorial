怎样使用这份手记

01 / 先把环境跑通

准备支持数据传输的 USB 线、开发板和 Python 工具。MicroPython 固件通常只需首次安装。

02 / 跟着一个案例完成闭环

阅读原理，修改对应案例的脚本，上传到板上，再按验收清单检查实际现象。

03 / 记录一个自己的变化

把闪烁变快，调整页面文案，或添加一个新案例。记录改了什么、为什么改、是否真的工作。

本教程的实测起点

macOS、Python 3.12.2、ESP32-D0WD-V3（4 MB Flash）、MicroPython 1.29.0。D2 在本板上按 GPIO2 使用。其他型号应先核对芯片、引脚和固件。

文件怎么找

目录 / 文件作用
examples/01-led-blink/案例 01 的教程、main.py 和部署清单
examples/02-wifi-led/案例 02 的教程、main.py、配置模板和部署清单
examples/03-bluetooth-led/案例 03 的 BLE 教程、main.py 和部署清单
examples/04-temperature-humidity/案例 04 的 DHT11 网页监测教程、main.py 和部署清单
config/wifi_config.py自己的 Wi-Fi 凭据，仅留在本地；分享包中没有此文件
scripts/device.py列出串口、选择案例、备份并上传、打开终端
templates/case/下一个案例的起点；尚未实现的内容必须标注待完成

本机直接双击 index.html 即可阅读；把分享 ZIP 解压后，其他学习者也从这个文件开始。后续案例按 05、06……顺序新增。
